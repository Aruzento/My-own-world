# Documentation Workflows

## Audit

Inventory only the requested surface. For each document identify audience, current owner, purpose, inbound usage and freshness against current code/contracts. Reuse an existing audit and recheck decisions at mutation time. Distinguish reference, how-to, explanation and tutorial where that resolves an ambiguity; no new taxonomy is required.

Separate confirmed gaps, duplicated authority and historical rationale. Check unique current content and callers before suggesting merge/archive/removal. A dated file or large byte count alone proves neither disuse nor uselessness. Preserve evidence and source revision. Analytics are optional observed data; unavailable page views/read traces cannot be simulated.

## Ownership

Name the authoritative contract/procedure and keep close to its code or existing docs zone. Determine whether a reference, how-to, explanation or tutorial serves the task using the existing doc-types guide when needed. Keep rationale/alternatives with a decision, and link operational readers to the current owner. Use a small task-to-owner router only where discovery needs it; avoid a mega-manual or parallel source of truth.

Distinguish customer, shared, internal, personal and generated material when their maintenance obligations differ. Personal drafts are not official dependencies; generated material inherits truth from its source. Compare platform/search/editor/versioning/access/cost options only when selecting documentation tooling is part of the task.

## Maintenance

Define an owner and change-triggered updates for the requested documents. Cadence follows audience/risk and the owner's agreement; it is not an automatic quarterly commitment for every file. Retire obsolete guidance deliberately, fix broken examples/links and preserve unique historical rationale where useful.

Update the affected procedure after an actual behavior/process change; do not require every implementation to write an ADR, log entry or generated manual. Reuse existing issue/release processes for unfinished work. Validate scoped links, metadata and executable examples with existing tooling. Report measured readership only if real telemetry exists.

Output only the requested audit, ownership map or maintenance decision; do not create all three by default.
